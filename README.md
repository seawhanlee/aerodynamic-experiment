# 공기역학 실험 (NACA 에어포일)

공기역학 실험 저장소에 오신 것을 환영합니다! 이 프로젝트는 오픈 소스 CFD 도구를 사용하여 다양한 NACA 에어포일(예: NACA 0012, NACA 23012, NACA 2412)에 대한 아음속 비점성 유동 해석을 수행하도록 설계되었습니다.

## 🚀 개요

이 프로젝트는 전산 유체 역학(CFD) 해석을 위해 다음 스택을 활용합니다:
*   **Gmsh:** 형상 생성 및 격자(Mesh) 생성을 위해 사용합니다.
*   **PyBaram:** 오일러 방정식(Euler equations)을 풀기 위한 CFD 솔버입니다.
*   **ParaView:** 유동 가시화 및 후처리를 위해 사용합니다.
*   **Python:** 데이터 분석 및 자동화 스크립트에 사용됩니다.

## 📁 디렉토리 구조

이 저장소는 원본 시뮬레이션 데이터와 스크립트 및 결과를 분리하여 구성되었습니다:

```text
.
├── scripts/            # 자동화를 위한 중앙 스크립트 (AoA 스윕, 격자 가져오기 등)
├── results/            # 분석용 노트북 및 중앙 가시화 상태 파일
│   ├── naca0012/       # NACA 0012에 대한 출력 이미지/플롯
│   ├── naca23012/      # NACA 23012에 대한 출력 이미지/플롯
│   └── ...
├── naca0012/           # NACA 0012 시뮬레이션 디렉토리
│   ├── mesh/           # 형상(.geo) 및 격자(.msh) 파일

│   └── naca0012.pbrm   # PyBaram 격자 파일

```

## 🛠️ 필수 요구 사항

시뮬레이션을 실행하기 전에 다음이 설치되어 있는지 확인하세요:

1.  **Gmsh** (격자 생성기)
2.  **PyBaram** (CFD 솔버)
3.  **ParaView** (가시화 도구)
4.  **Python 3.x** (`numpy`, `pandas`, `matplotlib` 설치 필요)

## 📖 사용 가이드

### 1. 격자 생성 및 가져오기

격자를 재생성하거나 새로 가져와야 하는 경우 (예: `naca0012`):

```bash
# 1. Gmsh를 사용하여 격자 생성
gmsh naca0012/mesh/naca0012.geo

# 2. PyBaram 형식으로 격자 가져오기
pybaram import naca0012/mesh/naca0012.msh naca0012/naca0012.pbrm
```

### 2. 받음각(AoA) 스윕 실행

다양한 받음각(0, 2, ..., 18도)에 대해 시뮬레이션을 자동으로 실행하려면:

1.  특정 에어포일 디렉토리로 이동합니다:
    ```bash
    cd naca0012
    ```
2.  중앙 스윕 스크립트를 실행합니다:
    ```bash
    sh ../scripts/sweep.sh
    ```
    *이 스크립트는 자동으로 `aoaX` 폴더를 생성하고, 각 각도에 대해 솔버를 실행하며, VTU 파일을 내보냅니다.*

### 3. 가시화

유동장(압력 계수, 마하 수 등)을 가시화하려면:

```bash
# 미리 설정된 상태 파일로 ParaView 열기
paraview --state=results/contours.pvsm
```
*참고: 특정 `aoaX` 폴더의 데이터를 불러오려면 ParaView 내에서 파일 경로를 조정해야 할 수 있습니다.*

### 4. 데이터 분석

받음각($\alpha$)에 따른 양력 계수($C_L$)를 플롯하려면:

1.  Jupyter Notebook 열기: `results/plot_CL_py.ipynb`
2.  첫 번째 셀에서 `profile` 변수를 원하는 에어포일로 설정합니다 (예: `'naca0012'`):
    ```python
    profile = 'naca0012'
    ```
3.  모든 셀을 실행합니다.
4.  결과 플롯은 `results/naca0012/` 디렉토리에 `cl.png`로 저장됩니다.
